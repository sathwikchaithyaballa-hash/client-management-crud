# Client Management CRUD Application

A full-stack client management application built with a React frontend and a Node.js/Express backend.

---

## Tech Stack

* **Frontend:** React, Vite, Tailwind CSS, Axios
* **Backend:** Node.js, Express
* **Database:** MongoDB (or your database of choice)
